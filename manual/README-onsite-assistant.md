# 조교용 현장 절차 — 신서버(gpu-new) 장애 점검

> **목표:** 서버실에 가서 ①눈으로 상태 확인 ②BMC 관리콘솔 접속 ③화면공유 켜기.
> **진단과 판단은 하지 않습니다.** 화면공유가 켜지면 그때부터 교수님이 원격으로 조작합니다.
> 대상 서버: **gpu-new (신서버)** — 랙 위치·외관은 별도 사진 참조.

> 🔒 **이 리포지토리는 공개입니다.** `<BMC-IP>` · `<노트북-IP>` · `<BMC-계정>`은
> 플레이스홀더이며, 실값이 채워진 조교 전달용 사본은 `README-onsite-assistant.local.md`에 있습니다
> (`.gitignore` 처리됨). **실값을 이 파일에 적어 커밋하지 마세요.**

---

## ⛔ 절대 하지 말 것

- **전원 버튼 누르지 않기** — 교수님 지시가 있을 때까지
- **케이블 뽑지 않기** (전원선·랜선 모두)
- **다른 서버 건드리지 않기** — 옆의 서버 4~5대는 **정상 가동 중**입니다.
  잘못 끄면 학생들 학습이 전부 날아갑니다. 반드시 gpu-new만.
- **BMC 설정값 변경하지 않기** — 보기만 합니다 (제조사 경고사항)
- 타는 냄새가 나면 → **아무것도 만지지 말고 즉시 전화**

**판단이 필요한 순간이 오면 멈추고 전화하세요.** 그게 정답입니다.

## 준비물

- [ ] **윈도우 노트북** (충전기 포함) — **유선랜 포트 또는 USB 이더넷 어댑터 필수**
- [ ] 랜케이블 1개 (2개면 더 좋음)
- [ ] 휴대폰 (사진 촬영 + 통화)
- [ ] 서버실 출입 카드/열쇠

> ⚠️ 요즘 노트북은 유선랜 포트가 없는 경우가 많습니다. **출발 전에 반드시 확인**하고,
> 없으면 USB 이더넷 어댑터를 챙기세요. 이거 없으면 현장에서 아무것도 못 합니다.

## 0단계. 눈으로 보기 (전원 켜기 전, 3분)

gpu-new 앞에 서서 아래를 **사진 찍어서 전송**하세요.

- [ ] **서버 앞면 전체** (전원 LED 상태가 보이게)
- [ ] **서버 뒷면 전체** — 랜포트 LED와 케이블이 어디에 꽂혀 있는지 잘 보이게. **가까이서 한 장 더**
- [ ] **옆의 다른 서버 앞면·뒷면** — 정상 상태와 비교하기 위한 대조군
- [ ] **랙 맨 위의 스위치(NETGEAR, 검은색 가로로 긴 장비)** ⭐⭐ — 랜선이 다 모이는 장비입니다.
      **포트마다 있는 작은 불이 하나하나 보이도록 가까이서** 찍어주세요. 정면에서 한 장, 비스듬히 한 장.

> ⭐⭐ **이 스위치 사진이 이번 방문에서 제일 중요합니다.**
> 랜선이 꽂힌 포트는 **7개**여야 정상입니다 (서버 6대 + 학교망 1개).
> - **불 켜진 포트가 7개** → 신서버 랜선은 살아있음. 서버 자체 문제
> - **불 켜진 포트가 6개 이하** → **랜선이 끊긴 것.** 원인 거의 확정
>
> 세어서 **"불 켜진 포트 O개"** 라고 숫자로 보고해주세요.

그리고 아래를 **말로 보고**하세요:

| 확인 항목 | 보고 내용 |
|---|---|
| 전원 LED | 켜짐 / 꺼짐 / 깜빡임 (색깔도) |
| 팬 소리 | 남 / 안 남 |
| **뒷면 랜포트 LED** ⭐ | 켜짐 / 깜빡임 / **꺼짐** ← 이게 제일 중요합니다 |
| **스위치 불 켜진 포트 수** ⭐⭐ | 몇 개인지 숫자로 (정상 = 7개) |
| 옆 서버와 비교 | 뭐가 다른지 |
| 냄새 | 이상한 냄새 있음 / 없음 |

> ⭐ **랜포트 LED가 꺼져 있으면** 랜선이나 스위치 문제일 가능성이 큽니다. 이 경우 서버는 멀쩡히
> 살아 있을 수 있어요. 반대로 **켜져 있는데도** 접속이 안 되면 서버 쪽 문제입니다.
> 그래서 이 관찰 하나가 원인을 크게 갈라줍니다. **꼭 확인해서 보고해주세요.**

## 1단계. BMC 관리콘솔 접속

BMC는 서버가 꺼져 있어도 **콘센트에 전기만 들어오면 동작**하는 별도 관리 장치입니다.
그래서 서버가 죽어 있어도 여기로는 들어갈 수 있습니다.

### 1-1. 랜케이블 연결

- [ ] 서버 뒷면에서 **`M`** 또는 **`MGMT`** 라고 쓰인 랜포트를 찾습니다 (다른 랜포트와 떨어져 있고 보통 1개)
- [ ] 랜케이블 한쪽을 그 포트에, 다른 쪽을 **노트북**에 꽂습니다
- [ ] ⚠️ **원래 꽂혀 있던 케이블은 뽑지 마세요.** M 포트가 비어 있어야 정상입니다.
      이미 뭔가 꽂혀 있으면 → **뽑지 말고 전화**

> 💡 **Wi-Fi는 켜둔 채로 두세요.** 유선은 서버 관리용, 무선은 인터넷/화면공유용으로 동시에 씁니다.

### 1-2. 노트북 IP 설정

**❗ 기본 게이트웨이는 반드시 비워두세요.** 여기에 뭘 적으면 Wi-Fi 인터넷이 끊겨서 화면공유를 못 합니다.

1. `제어판` → `네트워크 및 인터넷` → `네트워크 연결`
2. **이더넷** 아이콘 우클릭 → `속성`
   - USB 어댑터를 쓰는 경우 이름이 `이더넷 2`, `이더넷 3` 등일 수 있습니다.
     **랜선을 꽂았을 때 "네트워크 케이블 연결됨"으로 바뀌는 것**을 고르세요.
3. `인터넷 프로토콜 버전 4 (TCP/IPv4)` 선택 → `속성`
4. `다음 IP 주소 사용` 선택 후 입력:

   | 항목 | 값 |
   |---|---|
   | IP 주소 | `<노트북-IP>` |
   | 서브넷 마스크 | `255.255.255.0` |
   | 기본 게이트웨이 | **(비움)** |
   | 기본 설정 DNS | **(비움)** |

5. `확인` → `확인` (창 두 개 다 닫아야 적용됩니다)

### 1-3. 브라우저로 접속

1. 크롬 주소창에 입력: **`<BMC-IP>`**
   (이 주소가 신서버 BMC인 것은 **확인된 값**입니다. 다른 주소 시도할 필요 없습니다.)
2. "연결이 비공개로 설정되어 있지 않습니다" 경고가 뜨면 →
   `고급` 클릭 → 아래쪽 **`<BMC-IP>(안전하지 않음)(으)로 이동`** 클릭
   (이 경고는 정상입니다. 넘어가세요.)
3. **MegaRAC** 로그인 화면이 뜨면 성공
   - ID: `<BMC-계정>`
   - PW: 교수님이 따로 알려드립니다 (끝에 특수문자 있으니 그대로 입력)

### 1-4. 안 될 때

| 증상 | 다음 시도 / 보고할 내용 |
|---|---|
| 페이지가 안 열림 | ① 랜선 양쪽 다시 꽂기 ② 노트북 랜포트 LED 켜져 있는지 확인 ③ IP를 `확인` 두 번 눌러 제대로 적용했는지 재확인 |
| 그래도 안 열림 | **Wi-Fi를 잠깐 끄고** 다시 시도 → 되면 그대로 두고, 안 되면 Wi-Fi 다시 켜기 |
| 끝까지 안 됨 | ⚠️ **이게 오히려 중요한 단서입니다.** "BMC도 응답 없음"이라고 **그대로 보고**하세요. 서버에 전기 자체가 안 들어온다는 뜻일 수 있습니다. 실패도 정보입니다. |
| 로그인 실패 | 비밀번호 특수문자까지 정확히 입력했는지 확인 → 두 번 틀리면 **전화** |

## 2단계. 화면공유 켜고 대기 ← **여기가 핵심**

로그인에 성공하면 **더 이상 진행하지 말고**:

1. [ ] 교수님께 **전화**
2. [ ] 구글 미트(또는 줌/카톡) 켜고 **화면공유 시작**
3. [ ] 가능하면 **원격 제어 권한**도 넘겨주기

이후 조작은 교수님이 지시하거나 직접 합니다.
조교님은 화면공유를 유지하고, 물리적인 작업(케이블, 전원 버튼)이 필요할 때만 도와주시면 됩니다.

> 참고로 이후 진행될 내용: 메뉴에서 `Remote Control` → `Launch H5 Viewer` 를 눌러 서버 화면을 봅니다.
> H5 Viewer는 **새 창으로 열립니다.** 크롬이 팝업을 차단하면 주소창 오른쪽 끝에 차단 아이콘이 뜨니 눌러서 허용해주세요.

## 2.5단계. 추가 작업 — **교수님이 전화로 지시할 때만**

아래는 상황에 따라 요청드릴 수 있는 작업입니다. **먼저 하지 마시고, 지시를 받으면 그때 하세요.**

### (가) 랜케이블 바꿔 꽂기 — 스위치 포트 불량 확인용

> 💡 **안전 요령 — 이것만 지키면 사고 안 납니다.**
> **불이 꺼진 포트**에 꽂힌 랜선은 어차피 통신이 안 되는 선이니 옮겨도 안전합니다.
> **불이 켜진 포트는 절대 건드리지 마세요.** 그건 정상 동작 중인 서버입니다.

1. 스위치에서 **랜선은 꽂혀 있는데 불이 안 들어온 포트**를 찾습니다
2. 뽑기 전에 **사진**을 찍습니다 (원위치 복구용, 몇 번 포트인지 보이게)
3. 그 랜선을 **비어 있는 다른 포트**로 옮겨 꽂습니다
4. 30초 기다린 뒤 → 새로 꽂은 포트에 **불이 들어오는지**, 그리고
   **서버 뒷면 랜포트 LED가 켜지는지** 확인해서 보고
5. 변화 없으면 → **새 랜케이블로 교체**해서 같은 자리에 다시 시도

### (나) 스위치에 관리용 IP 넣기 — 앞으로 원격 진단하기 위한 작업

이 스위치는 웹 화면으로 관리할 수 있는 제품인데 **아직 IP가 없어서 원격으로 못 봅니다.**
IP만 넣어두면 다음부터는 랜선 상태를 교수님이 책상에서 확인할 수 있습니다.

- 노트북을 스위치 **빈 포트**에 랜선으로 연결한 뒤 **화면공유** 상태로 교수님께 넘기세요.
- 이후 설정은 교수님이 진행합니다. 조교님은 화면공유만 유지해주시면 됩니다.

### (다) M 포트를 스위치에 연결

- 1단계에서 M 포트에 꽂았던 랜선을 **M 포트 쪽은 그대로 둔 채**, 노트북 쪽 끝만 뽑아
  **스위치의 빈 포트**에 꽂습니다
- 해당 포트에 **불이 들어오는지** 확인 → **몇 번 포트인지 사진 + 숫자로 보고**

> ⚠️ 이 작업은 교수님이 사전 설정을 마친 뒤에만 지시합니다. 먼저 하지 마세요.

## 3단계. 마무리 — 노트북 원상복구

작업이 끝나면 **반드시** 되돌려 놓으세요. 안 그러면 노트북 유선랜이 계속 안 됩니다.

- [ ] 1-2의 같은 화면(`이더넷` → `속성` → `IPv4` → `속성`)에서
      **`자동으로 IP 주소 받기`** + **`자동으로 DNS 서버 주소 받기`** 선택 → `확인`
- [ ] 랜케이블 회수
- [ ] 서버실 원상복구 확인 (뽑은 것 없는지, 문 잠금)

## 요약 카드 (이것만 기억)

```
1. 사진 3장 찍어 보내기 (앞면 / 뒷면 / 옆 서버)
2. M 포트에 랜선 → 노트북
3. 노트북 IP: <노트북-IP> / 255.255.255.0 / 게이트웨이·DNS 비움
4. 크롬 → <BMC-IP> → 경고는 "고급 → 이동"으로 통과
5. ID <BMC-계정> / PW는 교수님이 알려준 것
6. 로그인되면 → 전화 + 화면공유. 여기서 끝.
7. 마무리: 노트북 IP를 "자동으로 받기"로 원복
```

**전원 버튼 누르지 않기. 다른 서버 건드리지 않기. 애매하면 전화.**
